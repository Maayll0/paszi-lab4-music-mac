# Материалы для отчёта

[Сценарий защиты](defense-scenario.md) описывает порядок демонстрации. [Результаты проверки](verification.md) относятся к ветке `main`.

Снимки хранятся локально в `screenshots/`. В папке `website/` показан интерфейс, в `database/` собраны схема и данные PostgreSQL, в `security/` показаны сетевые запросы и настройки cookie. В `tests/` находятся результаты автоматических проверок и запуска Compose.
