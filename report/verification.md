# Проверка MusicAccess

Локальный стенд запущен в Docker Desktop на Windows. PostgreSQL, бэкенд и фронтенд прошли проверки готовности. Сайт открыт через Nginx на http://localhost:8080.

- На пустой схеме PostgreSQL Alembic применил миграцию `0001` и создал таблицы. Команда `alembic check` подтвердила соответствие схемы моделям.
- В PostgreSQL есть таблицы пользователей, песен и сессий. Сессия связана с пользователем внешним ключом. Доступ к песням определяется сравнением уровней. Представлений VIEW в этой версии нет.
- Сквозная проверка через Nginx прошла регистрацию, вход, поиск, получение части аудиофайла, отказ при недостаточном допуске и удаление тестового аккаунта.
- На изолированной SQLite прошёл 31 тест pytest, включая девять сочетаний уровней пользователя и песни. Starlette выдал предупреждение об устаревшем адаптере httpx.
- Сборка фронтенда прошла. В Edge прошли 4 браузерных теста Playwright. Проверены действия с аккаунтом, поиск и фильтры, воспроизведение, перемотка, отказ в доступе и переключение песен.
